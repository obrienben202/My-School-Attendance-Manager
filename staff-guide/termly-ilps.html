Termly learner ILP reviews

Termly learner ILP reviews: overview

Learners complete a private termly review and submit it to their assigned RG teacher. Administrators run the set-up; RG teachers review.

The termly guide is split into these pages, in the order they are normally used:

  1. Set up learner sign-in (no public signup)
  2. Link an account to a learner record
  3. Assign an RG teacher
  4. Publish a term
  5. Edit a future template version
  6. Review submissions (RG teachers)
  7. Start the next academic year
  8. Short guide for learners
Check before relying on this page. The current portal only opens the Termly ILPs administration page (/ilp-admin/termly) for the Admin role. This page is kept as originally written; ask the Admin Team if you cannot open it.
