Termly learner ILP reviews

Edit a future template version

What to look for

  1. Clone as new draft version. A published version is locked, so clone it first.
  2. Sections and questions. Reorder sections with the arrow buttons; Add question, Required, delete.
  3. Preview draft. Read it as a learner would.
  4. Save template, then Publish version. In-progress reviews keep their original version.
  1. Open the Templates tab and choose the template. A published version is locked.
  2. Select Clone as new draft version. Edit titles, welcome, instructions, end-of-term guidance, target examples, sections (arrow buttons reorder) and questions (Add question, Required, delete).
  3. Select Preview draft to read it as a learner would, then Save template and Publish version. Reviews already in progress keep their original version.
Check before relying on this page. The current portal only opens the Termly ILPs administration page (/ilp-admin/termly) for the Admin role. This page is kept as originally written; ask the Admin Team if you cannot open it.
