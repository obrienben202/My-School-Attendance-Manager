Termly learner ILP reviews

Link an account to a learner record

What to look for

  1. Search box. Find the learner by name or exact Person code.
  2. Person code. Check the code against the school roster; a matching name alone is not proof.
  3. Learner account. Choose the individually verified account.
  4. Save. Stores the mapping; the confirmation appears only once it is stored.
  1. Go to ILP Admin → Termly ILPs → People tab.
  2. Find the learner by name or exact Person code (use the search box). Verify both the account and exact code against the authoritative school roster before linking. A learner-supplied code or matching name alone is not proof of identity.
  3. In Learner account choose the individually verified account and select Save. The server checks that the account has a directory-owned learner role, the code identifies one confirmed learner, and the account is not linked elsewhere. The confirmation banner appears only once the mapping is stored.
Check before relying on this page. The current portal only opens the Termly ILPs administration page (/ilp-admin/termly) for the Admin role. This page is kept as originally written; ask the Admin Team if you cannot open it.
