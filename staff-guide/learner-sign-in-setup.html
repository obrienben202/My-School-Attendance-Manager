Termly learner ILP reviews

Set up learner sign-in (no public signup)

What to look for

  1. Sync from Google Sheet. Run after learner accounts are added to the school directory.
  2. Role learner or student. Each learner needs an individual account with this directory role.
  3. Message for an unlinked learner. A learner not yet linked sees this and no data.
Student login sheet
Open the student login sheet (opens in a new tab)

This setup is for student accounts only. Staff already have their own logins.

  1. The school must first create an individual school account for each learner and add it to the school directory with role learner or student. Open User Management (/admin/users) and select Sync from Google Sheet.
  2. Learners sign in with their school username and password. The external password service (GAS) verifies credentials; the validated school directory owns roles. There is no public signup. Do not use shared accounts.
  3. A signed-in learner who is not yet linked sees Your account is not linked to a learner record yet and no data.
Check before relying on this page. The current portal only opens the Termly ILPs administration page (/ilp-admin/termly) for the Admin role. This page is kept as originally written; ask the Admin Team if you cannot open it.
