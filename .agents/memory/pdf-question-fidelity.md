---
name: PDF question fidelity
description: Preserve whole discussion bullets when verifying a form against a source PDF.
---
Compare complete discussion bullets, not only the text up to the first question mark, and distinguish instructional bullets from discussion prompts.

**Why:** A single discussion bullet in the supplied ILP PDF can include a main question and a follow-up question. Its target-review instructions also contain question-like bullets that are not part of the 53 discussion prompts.

**How to apply:** When checking future content changes against this PDF, verify the full bullet wording within the substantive question sections, as well as counts and grouping.
